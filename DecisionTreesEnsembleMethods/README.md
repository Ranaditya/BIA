# Iris Species Prediction - Decision Trees

Objective:
Build a Decision Tree model on the Iris dataset to predict the target class, Species.

Current Progress:
Step 1 is complete.

- Imported the required libraries.
- Loaded the Iris dataset from the local CSV file in the data folder.
- Added a fallback loader using sklearn load_iris.
- Added a dataset inspection utility for shape, dtypes, missing values, and preview rows.

Project Structure:

- DecisionTreesEnsembleMethods/data/
- DecisionTreesEnsembleMethods/data_loader.py
- DecisionTreesEnsembleMethods/eda.py
- DecisionTreesEnsembleMethods/preprocessing.py
- DecisionTreesEnsembleMethods/model.py
- DecisionTreesEnsembleMethods/main.py
- DecisionTreesEnsembleMethods/README.md

Run Step 1:

1. Open terminal in DecisionTreesEnsembleMethods.
2. Run: python main.py
